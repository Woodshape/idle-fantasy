Idle Fantasy Combat

Basic Combat Loop

Combat is a discrete tick simulation. Movement can remain smooth, but combat decisions, cooldowns, recovery, casts, action ordering, hit rolls, damage, and defeat checks happen only on simulation ticks.

The first implementation supports one adventurer against one monster, one basic attack, one adventurer skill, per-action cooldowns, and a global cooldown after skills and spells.

Core Rules

Tick Authority

Combat advances on simulation_tick. No combatant attacks between ticks.

Action Queue

Ready combatants choose an available action, enter Queued, then wait for ordering.

Cooldown Gates

Basic attack, skills, spells, casts, recovery, and global cooldowns are integer tick counters.

State Machine

Tick Flow

  1. The game emits simulation_tick.
  2. Each active encounter emits combat_tick_started.
  3. Combatants reduce cooldown, cast, recovery, and global cooldown counters.
  4. Finished casts queue their completed action.
  5. Ready combatants choose the first available action by priority.
  6. Queued actions roll initiative scores and sort by action order.
  7. Actions resolve in sorted order. A dead target cancels later queued actions.
  8. Damage, death, rewards, encounter end checks, and bridge state updates are published.
  9. The encounter emits combat_tick_completed.
Current tick interval is 0.25 seconds. A 4 tick cooldown is 1 second of simulation time.

Entity Stats

Stat Meaning Current Example
Health / MaxHealth Current and maximum hit points. A combatant at 0 health becomes Defeated. Mira 28 HP, Slime 18 HP.
Attack Base damage before action multiplier and defender defense. Mira 7, Slime 3.
Defense Flat reduction from successful incoming damage. Mira 1, Slime 1.
Accuracy Flat probability modifier added to the attacker's hit chance. 0.20 means +20 percentage points. Mira 0.20, Slime 0.00.
Evasion Flat probability modifier subtracted from incoming hit chance. 0.15 means -15 percentage points for attackers. Mira 0.15, Slime 0.00.
Initiative Flat bonus to action ordering when multiple combatants queue on the same tick. Mira 4, Slime 1.
AttackSpeed Basic attack cooldown in ticks. Lower values attack more often and win tie breakers. Mira 4 ticks, Slime 8 ticks.
Hit chance is currently clamp(0.75 + attacker_accuracy - defender_evasion, 0.05, 0.95). For example, Mira attacking Slime is 0.75 + 0.20 - 0.00 = 0.95, or 95%. Slime attacking Mira is 0.75 + 0.00 - 0.15 = 0.60, or 60%.

Ability Stats

Field Meaning
ActionId Stable id used by logs, bridge events, cooldown maps, and tests.
ActionKind BasicAttack, Skill, or Spell. Skills and spells start global cooldown.
CooldownTicks Per-action cooldown for skills and spells. Basic attack uses the owner's AttackSpeed tick value.
CastTicks Ticks spent casting before the action queues. Zero means instant.
RecoveryTicks Post-action lockout before returning to Ready.
ActionWeight Penalty or bonus in action ordering. Higher weights act later; negative weights act earlier.
DamageMultiplier Multiplies the attacker's Attack before defense is subtracted.
UsesGlobalAttackCooldown Starts the owner's basic attack cooldown after resolving.

Basic Attack

Instant action. Its cooldown is the combatant's AttackSpeed tick value. Mira's basic attack cooldown is 4 ticks. Slime's is 8 ticks.

Heavy Strike

Adventurer skill. It is instant, has a 4 tick skill cooldown, 1 tick recovery, 1.5x damage, and starts the 4 tick global cooldown after it resolves.

Combat Example

This example shows why a skill no longer immediately chains into a basic attack after the global cooldown change.

Tick 14 Mira and Slime are Ready. Mira queues heavy_strike; Slime queues basic_attack. Both roll initiative order. After Heavy Strike resolves, Mira starts heavy_strike cooldown for 4 ticks, recovery for 1 tick, and global cooldown for 4 ticks.
Tick 15 Mira's 1 tick recovery completes, so her state returns to Ready. She still cannot act because global cooldown has 3 ticks remaining.
Ticks 16 and 17 Mira remains Ready but waits. Her global cooldown and Heavy Strike cooldown continue counting down.
Tick 18 Global cooldown and Heavy Strike cooldown reach zero. Mira can choose an action again. Since Heavy Strike has priority over basic attack and is ready, she queues Heavy Strike.

Debugging Quick Reference

Log or Event Use
COMBAT_STATE tick=... Shows visible state transitions. Internal Queued transitions are suppressed in console output.
ACTION_QUEUED tick=... Shows selected action, configured cooldown, current basic cooldown, current global cooldown, cast ticks, and recovery ticks.
combat_action_order_rolled Bridge event with random roll, initiative bonus, attack speed bonus, action weight, and final score.
combat_action_cooldown_started Bridge event for basic attack, skill, spell, and global cooldown start.
combat_action_cooldown_ready Bridge event emitted when a cooldown counter reaches zero.
