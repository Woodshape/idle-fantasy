# Idle Fantasy Backlog

## Missing Or Deferred

- Full game design systems remain missing by design: hiring UI, settlement economy/services, shops, equipment, inventory, parties, possession, dungeons, procedural world, save/load, resurrection, and level-up/stat growth.
- Combat effects are not implemented: buffs, debuffs, regeneration, damage-over-time, healing-over-time, and status duration ticking.
- Multi-combatant encounter hardening is incomplete because the architecture verifier fails and the monster claim registry is not globally safe.
- Reward splitting and party-grade reward ownership are not implemented; rewards are collected by the controller/adventurer that transitions through `CollectLoot`.
- `CombatDecisionController` currently treats `runner.Loadout.Actions` order as deterministic AI priority. If future behavior needs weighted, contextual, or class-specific action choice, introduce an explicit priority/scoring field instead of relying only on `.tres` array order.
